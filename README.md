# 🌊 Aqua World

An interactive underwater-themed login page built with pure HTML, CSS, and JavaScript.

A scuba diver, manta ray, sea turtle, jellyfish, and colorful fish swim around the screen. When you click the password field, they hide behind the coral to give you "privacy" 🙈.

## ✨ Features

- 🐠 Animated sea creatures (diver, manta ray, turtle, jellyfish, clownfish, blue tang, yellow tang, moorish idol)
- 🙈 **Privacy mode**: creatures swim away when you type your password
- 👁️ Show/hide password toggle
- 🫧 Floating bubbles, glowing plankton, and sunlight rays
- 💧 Water ripple effect when you click the background
- 🐟 Creatures dart away from your mouse and clicks
- 🔊 Ocean sound and bubble pops (made with the Web Audio API, no audio files)
- 🪟 Glassmorphism login card with toast messages

## 📁 Files

```
├── index.html   # Page structure and SVG sea creatures
├── style.css    # Ocean theme, animations, and layout
└── script.js    # Creature movement, interactions, and sound
```

## 🚀 How to Run

1. Download all three files into the same folder.
2. Open `index.html` in any modern browser.

No installation or server needed.

## 🎮 How to Use

- Move your mouse near the fish and they swim away.
- Click on the water to make a ripple.
- Click the password box to see the creatures hide.
- Click **Ocean Sound** (top right) to turn sound on or off.

## ⚠️ Note

This is a **front-end demo only**. The login form shows a welcome message but does not check real accounts or connect to a backend.

## 🛠️ Built With

- HTML5
- CSS3 (animations, glassmorphism)
- Vanilla JavaScript (OOP classes, Web Audio API)
